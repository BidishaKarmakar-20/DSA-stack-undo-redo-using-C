4. How Dual-Stack State Management Works

  • Edit Operation (Type / Delete): Before modifying currentText, push the current snapshot onto undoStack. Any new edit invalidates the forward timeline, so redoStack.top is reset to -1.
  • Undo Operation (Ctrl+Z): Check !isEmpty(&undoStack). Push currentText onto redoStack, then pop the top snapshot from undoStack into currentText.
  • Redo Operation (Ctrl+Y): Check !isEmpty(&redoStack). Push currentText back onto undoStack, then pop the top snapshot from redoStack into currentText.
  • Overflow Policy: When undoStack reaches MAX - 1, an array-based C stack can either reject new history or shift elements left (circular/drop-oldest policy) to retain recent states.
